Reliability is how consistently two random halves of the items rank the monitored checkpoints (1 is perfect; it is undefined, shown as n/a, when the score never moves). An eval at its ceiling can still show a regression but can no longer show an improvement.

How to read this

Regression alerts. Each monitored checkpoint is compared with the checkpoints 1 and 4 back, on the same items. Only items whose result flipped carry evidence: under no change a flip is as likely to be a loss as a gain (exact McNemar test).

Repeated looks. The run has 22 monitored checkpoints and 8 evals, so 352 tests. One budget of 0.05 is split evenly over all of them. If the model never changed, the chance of any regression alert in the whole run is at most 0.05.

What the guarantee does not cover. A checkpoint that is really a little worse than the last one is a real change, even if it heals by itself. Such dips are flagged. An alert means the items say the model changed; it does not say why.

Model or eval. A regression is blamed on the model only if it also shows when the same outputs are graded by a second, independent grader. If the two graders start to disagree, the grader is blamed. If the main items pull ahead of a fresh twin set drawn the same way, the eval is marked contaminated.
